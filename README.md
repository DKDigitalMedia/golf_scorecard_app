🏌️️ YAGS - Yet Another Golf Scorecard

User Guide

⸻

📱 Overview

Yet Another Golf Scorecard (YAGS) is a simple, fast, and offline-friendly app designed to track your golf rounds with minimal effort.

The goal: enter data quickly and keep playing.

⸻

🚀 Getting Started

1. Create a Course

Before starting a round, you’ll need to set up a course.
	•	Go to Courses
	•	Tap Add Course
	•	Enter:
	•	Course Name
	•	Tee Boxes (name, rating, slope, optional total yardage)

⸻

2. Edit Course Holes

Set up hole details for your course:
	•	Tap Edit Holes
	•	Enter:
	•	Par (3, 4, or 5)
	•	Stroke Index (SI) (1–18, optional)
	•	Yardages (optional, per tee box)

👉 Tip:
	•	Par & Stroke Index are set once per course
	•	Yardages are set per tee box

⸻

⛳ Starting a Round
	•	From the main screen, tap Start Round
	•	Select:
	•	Course
	•	Tee Box
	•	Tap Start

If you leave mid-round, you can Resume Round later.

⸻

📝 Entering Hole Data

For each hole, you’ll enter:

Score
	•	Tap the number of strokes (quick chip selection)

Putts
	•	Select number of putts

Tee Shot (FIR)
	•	Choose:
	•	Left
	•	Center (fairway)
	•	Right

Optional Stats
	•	Penalties
	•	Clubs used
	•	Approach details
	•	Notes

👉 The screen is designed for fast entry:
	•	Large tap targets
	•	Minimal typing
	•	Quick navigation between holes

⸻

📊 Round Summary

At the end of the round, you’ll see:
	•	Total Score
	•	Front 9 / Back 9
	•	FIR %
	•	GIR %
	•	Total Putts
	•	Penalties

Tap Finish Round to save.

⸻

📁 Viewing Past Rounds
	•	Go to Rounds
	•	View completed rounds with:
	•	Date
	•	Course
	•	Score
	•	Tap a round to see full details

⸻

🛠️ Managing Courses
	•	Go to Courses
	•	Edit:
	•	Course info
	•	Tee boxes
	•	Hole data

⸻

💡 Tips for Best Use
	•	Set up your course before your round
	•	Use chips instead of typing whenever possible
	•	Keep it simple — only track what you care about
	•	Works fully offline — no internet needed

⸻

🎯 Design Philosophy

This app is built around one idea:

Don’t slow down the round.

	•	Fast input > fancy features
	•	Simple UI > clutter
	•	Offline-first > always works

⸻

❓ FAQ

Do I need internet?
No — everything works offline.

Can I customize courses?
Yes — full control over tee boxes, pars, yardages, and SI.

Does it track advanced stats?
Basic stats are included. The focus is simplicity over complexity.

⸻

🏁 Final Notes

This app is designed by a golfer, for golfers who want:
	•	Less tapping
	•	Less thinking
	•	More playing
